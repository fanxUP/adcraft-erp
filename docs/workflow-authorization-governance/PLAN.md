## 2. 后续批次（本轮不改）

### P-GOV-04：明细工作单与任务编排

将明细 × 阶段抽象为工作单，任务卡片仅作为聚合视图；补齐幂等键、乐观锁和事务事件。需要单独的数据迁移评审。

### P-GOV-05：查询投影

为工作台、项目看板、完成项目、经营驾驶舱和成本列表建立批量查询投影，移除序列化器中的 N+1 查询和 Python 全量分页。

### P-GOV-06：敏感字段和附件策略

统一订单价格、明细价格、成本、外协、附件查看/下载/删除的字段与对象策略，覆盖聊天、导出、AI 和下载通道。

### P-GOV-07：应用服务拆分

将 `BusinessDocumentService` 拆为订单命令、订单查询、明细变更、阶段编排、财务投影等边界；将三类任务服务抽成共用执行器和阶段策略。

### P-GOV-08：清理与发布

在静态契约、全量测试、性能和安全验证通过后，再移除确认无调用的 legacy 分支。发布必须单独走部署/迁移门禁。
