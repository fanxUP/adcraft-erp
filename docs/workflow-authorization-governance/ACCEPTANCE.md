# 业务流程与权限治理验收标准

## A-GOV-01：治理基线

- [x] Git 分支和基线已记录，工作区无未说明的用户改动。
- [x] `.vibe/CHANGE_BUDGET.yaml` 和 `.vibe/SCOPE_LOCK.yaml` 已声明本批次预算与范围。
- [x] 本阶段没有新增数据库迁移、第三方依赖或业务数据修改。
- [x] 缺失本地运行依赖等环境限制已单独记录，没有将未执行的测试记为通过。

## A-GOV-02：状态机注册表

- [x] 订单、报价、合同、验收、设计、制作、安装、外协八类流程均在注册表中登记。
- [x] 旧 `*_WORKFLOW` 映射由注册表导出，现有调用方和错误文案兼容。
- [x] 每条转换都有稳定命令标识和中文展示名称。
- [x] 任意转换目标都已登记，注册表映射不可在运行时修改。
- [x] 已覆盖终态不可流转和现有重要阶段转换的回归测试。

## A-GOV-03：统一授权策略

- [x] 阶段读取、任务分配、订单任务范围和外协读取均经过统一策略入口。
- [x] 只有模块读取权限时，不能自动得到全部订单/任务范围。
- [x] 按执行人范围只能让匹配当前用户的对象通过；其他用户被拒绝。
- [x] 超级管理员和内部服务调用保持既有语义，但普通角色不绕过范围策略。
- [x] 权限依赖、冲突和敏感字段判断仍由现有 `AuthorizationEvaluator` 负责，没有重复算法。
