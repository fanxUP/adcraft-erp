# 验收标准：单项状态操作与附件日期相册

## A01：单项状态交互

- 设计、制作、安装任务详情中，正常状态推进不再依赖勾选框、阶段全选框或批量“变更状态”卡片。
- 每条明细有独立操作列；一次点击只针对当前这一条明细。
- 点击整行、项目内容、状态标签不会隐式变更状态。
- 操作前能看到明确的当前状态和目标状态确认文案；请求期间只锁定当前行。
- 当前行操作成功后，其他明细的状态、执行人、进度、完成时间和日志不发生变化。

## A02：服务端单项安全与工作流兼容

- 三类任务的状态接口接收单条 ID 时，只更新该 ID 对应的关联记录。
- 服务端仍校验当前状态、目标状态、岗位权限、明细分配/领取关系、任务关联关系和外协前置条件。
- 普通员工只能推进自己岗位负责的流程；未分配明细可由有权员工领取，已由他人负责的明细不能被普通员工操作。
- 生产、安装的进行中外协任务继续阻止完成动作；提示按用户外协权限脱敏。
- 执行人、`item_completed_at`、状态日志操作人/时间只写当前明细；任务聚合进度和完成状态按全部明细重新计算。
- 现有接口的批量字段仍兼容历史调用；本次任务详情 UI 不再构造批量 ID 列表。
- 已有回退动作仍可按工作流使用，例如“制作中 → 待制作”。

## A03：桌面端三类任务逐条操作

- 设计、制作、安装三个桌面详情入口都使用同一套逐条操作语义。
- 未关联且可进入当前流程的明细显示“加入并开始”；历史/结束任务按权限显示“添加到本任务”或只读。
- 已完成、已取消、无权限、他人负责、外协阻断的行显示禁用状态和普通语言原因。
- 设计、制作、安装人员可以看见允许查看的订单其他流程状态，但不能操作不属于自己岗位的流程。
- 页面不再残留失效的批量选择按钮、无用途的 selected state、死 handler 或仅为旧批量 UI 服务的死样式。

## A04：移动端安装逐条操作

- 移动安装任务详情不再把 `currentTask.order_item_ids` 全部提交给状态接口。
- 移动端每次状态操作只提交被点击明细的 ID；完成一条时其他明细不变。
- 移动端显示与桌面端一致的状态动作、执行人限制、外协阻断和大白话错误提示。
- 移动端完成一条明细后，任务聚合进度只按真实明细状态刷新；不出现无关明细一起完成或任务错误跳到 100%。
- 现场照片与视频上传入口仍可用，权限、格式和大小限制不变。

## A05：服务端时间驱动的附件相册

- 设计任务附件、制作任务附件、安装任务现场照片与视频继续从订单级附件接口读取，不要求先创建任务。
- 新上传资料的日期时间来自服务端 `created_at`；客户端不能伪造或编辑上传时间。
- 日期按本地日期分组且新日期在前；同一天内按上传时间新到旧；不使用原始字符串截取日期。
- 覆盖 UTC 时间转换和跨午夜边界：服务端时间转换到当前业务浏览器日期后，资料进入正确日期组。
- `created_at` 为空的旧资料归入“时间未知”组，不被删除、不被擅自补时间。
- 每个日期组显示日期和资料数量；图片/视频使用媒体网格，PDF/Word/Excel/CAD/压缩包等普通文件使用文件行，不强行显示缩略图。
- 图片可点击放大，视频可打开播放，普通文件按类型提供预览或下载；删除后从日期组移除，空组消失。
- 上传、失败重试、下载、预览、删除和权限行为在订单详情、设计/制作/安装任务详情、完成项目详情、移动安装入口保持一致。

## A06：回归、构建与代码纯净度

- 后端相关单元测试通过，至少覆盖单项更新、权限/领取、外协阻断、回退、聚合进度和日志时间。
- 前端相关测试通过，至少覆盖动作映射、单 ID 请求、移动端防整单提交、日期分组、排序、空日期、媒体和普通文件。
- 前端类型检查、构建、lint/格式检查和 `git diff --check` 通过；后端测试/静态检查按项目现有命令通过。
- 无新增数据库迁移、无不必要依赖、无价格或外协信息越权展示。
- 旧批量 UI 清理后没有新增未使用导入、死组件、死样式或“看起来可点击但没有效果”的按钮。
- 不以“接口返回成功”替代页面和数据验证；至少用测试或可重复的本地验证证明每条明细的隔离性。

## 验收场景矩阵

| 场景 | 预期结果 |
| --- | --- |
| 设计任务有 3 条明细，点击第 2 条“完成设计” | 只有第 2 条变为已完成；第 1、3 条原样保留 |
| 员工点击未分配明细“开始制作” | 只领取并推进这一条；其他可见明细不被分配 |
| 普通员工点击他人已领取明细 | 按钮不可用或服务端拒绝，显示负责人和可读原因 |
| 安装明细存在进行中外协，点击“完成安装” | 服务端拒绝；不改变状态、执行人、完成时间或进度 |
| 移动安装点击一条明细完成 | 请求只含这一条 ID，不提交整张任务明细列表 |
| 同时上传照片、视频、PDF | 每个文件按服务端上传时间进入当天分组；媒体为缩略图/播放入口，PDF 为文件行 |
| 资料跨本地午夜上传 | 按统一时间格式化后的本地日期进入正确日期组 |
| 删除日期组最后一个文件 | 文件删除成功，日期组随之消失 |
| 历史附件无上传时间 | 进入“时间未知”组，不伪造时间、不丢失文件 |
