# 项目成本字段精简验收标准

## 页面

- 登记和编辑弹窗的财务字段顺序为：日期、供应商、支付金额、欠款金额、分类、付款方式、支出总额、说明、凭证。
- 成本摘要、产品/材质/工艺、规格尺寸、数量、单位、单价、收款公司不再渲染。
- 订单/报价和成本归属仍可正常使用，多明细归属仍只登记一笔总额。
- 项目成本列表不再出现被移除的业务列，供应商列不再命名为“供应商/收款公司”。
- 凭证仍支持拖拽/选择上传、图片预览、文件查看和删除。

## 金额与应付

- 支付金额为 100、欠款金额为 30 时，支出总额显示 130，并保存为 `amount=130`、`debt_amount=30`。
- 欠款为 0 时，支出总额等于支付金额，不生成待付款台账。
- 欠款大于总额、任何金额为负数或总额为 0 时不能保存或导入。
- 已有应付付款流水的成本仍遵守原有修改和删除保护。

## 兼容性

- 历史成本记录可以打开、编辑基本财务字段并查看凭证。
- 旧 API 和旧 Excel 字段不会导致接口或导入崩溃；新模板使用精简字段。
- 旧数据库列不删除，项目成本汇总、应付管理和供应商统计不改变口径。

## 工程质量

- 后端测试、前端测试、类型检查、Lint 和生产构建通过。
- `git diff --check`、scope check 和 merge quality gate 通过。
- 部署后服务健康检查通过，关键页面返回新构建版本。
