# 项目成本字段精简实施计划

## 模式与范围

- 模式：STRICT。
- 类型：项目成本登记表单、成本列表、金额映射、导入模板和兼容接口调整。
- 不新增数据库迁移，不物理删除历史列，不新增第三方依赖，不修改经营支出页面。

## 执行项

### P01：金额归一化与回归测试

- 新增纯函数，统一计算支付金额、欠款金额和支出总额。
- 覆盖零值、负数、欠款大于总额和两位小数边界。
- 增加后端服务测试，确保新页面保存的总额仍进入现有 `amount`，欠款仍进入应付台账。

### P02：项目成本登记/编辑表单

- 移除冗余属性字段和收款公司输入。
- 调整字段顺序和中文标签。
- 支出总额改为只读计算值。
- 供应商移动到日期后面，凭证拖拽上传功能保持不变。

### P03：项目成本列表和类型

- 列表按日期、供应商、支付金额、欠款金额、分类、付款方式、支出总额、说明、凭证展示。
- 保留编号、成本归属和操作等业务定位信息。
- 增加派生支付金额类型字段，不暴露旧冗余列。

### P04：Excel 模板与旧数据兼容

- 新模板只展示精简字段。
- 旧解析列继续兼容但不写入新表单字段。
- 新导入校验支付金额、欠款金额和支出总额的一致性。

### P05：验证、提交与部署

- 执行后端测试、前端测试、类型检查、Lint、生产构建、差异范围和敏感信息检查。
- 先确认 GitHub 目标提交，再在服务器执行已有部署脚本。
- 部署后验证健康接口、服务状态、成本详情关键路径和旧数据读取。
