# 订单级三阶段资料源实施计划

## 任务分类

- 类型：跨后端、数据库、前端和权限边界的附件归属重构。
- 模式：STRICT。涉及文件上传、下载、删除、历史数据迁移、岗位权限和订单范围隔离。
- 目标：让订单成为设计、制作、安装三类资料的唯一源头，任务详情页只作为阶段入口。
- 依赖预算：不新增第三方依赖；需要一条可回滚、可 dry-run 的 Alembic 元数据迁移，不搬动物理文件。
- 非目标：不调整任务状态机、任务进度、任务分配、外协逻辑、价格字段或其他模块附件。

## 计划项

### OSA-P01：锁定订单级归属、接口和权限契约

- 把附件所有权固定为 `order_id + stage`，明确 `task_id` 不再是必填或所有权字段。
- 先增加后端服务、路由和权限契约测试，再改前端。
- 明确订单入口与设计/制作/安装任务入口的权限矩阵和不可见数据范围。
- 确定旧接口的过渡适配方式，避免发布后出现两套写入路径。

对应验收：A-OSA-01。

### OSA-P02：增加订单级附件数据模型和统一服务

- 为通用 `attachments` 表增加可空 `order_id`、`stage` 字段及索引/校验。
- 建立统一订单资料服务，所有列表、上传、下载、删除都按订单级字段执行。
- 保留现有文件校验、路径隔离、图片/视频分类和审计能力。
- 订单资料响应不返回物理路径，不依赖任务是否存在。

对应验收：A-OSA-02。

### OSA-P03：历史资料回填与旧接口兼容

- 以 dry-run 统计三类旧任务附件、可映射记录和孤儿记录。
- 将可映射历史记录补齐 `order_id`、`stage`，保留原任务关联字段和物理文件。
- 旧 `/orders/.../task-attachments`、旧 `/attachments/upload` 在过渡期转调订单资料服务。
- 迁移和兼容路径必须幂等，其他模块附件数据不得变化。

对应验收：A-OSA-03。

### OSA-P04：统一订单、任务和完成详情的前端入口

- 用共享阶段附件组件替换订单详情按任务循环的上传区。
- 设计、制作、安装任务详情分别只展示和操作订单对应阶段资料。
- 完成项目详情改为三个订单阶段只读资料区，消除同一安装资料按多张任务重复展示。
- 保留拖拽上传、缩略图、放大、视频播放、文件列表、下载、删除和失败重试。

对应验收：A-OSA-04。

### OSA-P05：安全边界、权限回归和数据一致性验证

- 验证订单越权、附件 ID 猜测、任务入口跨阶段访问、价格字段泄露和公开文件路径风险。
- 验证同一资料从订单详情、任务详情和完成详情读取的一致性。
- 验证无任务、任务完成、任务删除、任务重建和订单恢复等生命周期场景。
- 检查是否存在旧任务接口继续写入非订单级记录的死路径。

对应验收：A-OSA-05。

### OSA-P06：全量质量门禁与发布准备

- 执行后端迁移 dry-run、后端测试、前端测试、typecheck、lint、生产构建和差异检查。
- 检查数据库迁移升级/回滚说明、文件数量核对和服务启动健康状态。
- 记录接口兼容窗口和旧接口调用监控，准备发布说明和回滚步骤。

对应验收：A-OSA-06。

## 发布顺序

1. 先发布兼容代码和数据库新增字段，旧数据仍可读。
2. 执行 dry-run，核对可迁移数量、孤儿数量和物理文件数量。
3. 执行元数据回填，验证迁移前后附件数量和文件路径不变。
4. 发布新前端，所有三类任务详情改调订单级接口。
5. 观察旧接口调用；确认无调用后再删除旧写入逻辑。

## 当前实施状态

- OSA-P01 至 OSA-P04 已完成代码实施：订单级字段、统一服务、兼容适配器、共享前端组件和完成详情只读入口已落地。
- OSA-P05 已完成自动化回归：后端附件/权限用例及前端跨入口静态契约已通过，且未发现任务详情继续调用旧上传/删除入口。
- OSA-P06 的本地代码质量检查已通过；生产数据库迁移、服务器部署和真实环境健康检查尚未执行，需在发布阶段按上面的顺序执行。
- 本次迁移只补充附件元数据，不移动、不复制、不删除 `LOCAL_UPLOAD_DIR` 中的物理文件。

## 回滚原则

- 应用回滚优先回到兼容版本，不先回滚数据库字段；新增字段对旧版本可为空。
- 回滚前确认新版本没有产生旧版本无法解释的关键业务数据；必要时保留新字段和订单级记录，避免附件丢失。
- 不使用删除表、删除文件、清空附件或强制重建任务的方式回滚。
- 迁移脚本不移动物理文件，失败时只回滚元数据事务并保留 dry-run 报告。
