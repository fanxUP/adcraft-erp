# TCD-P01 经营驾驶舱项目与明细完成统计实施计划

## 1. 任务类型、风险与模式

- 类型：经营驾驶舱统计、任务明细完成事件、员工行级数据隔离、模块化权限扩展。
- 风险：高。统计口径错误会造成管理决策错误；员工范围过滤错误会造成他人任务/明细越权；月份边界和返工回退容易重复计数。
- 实施模式：STRICT。
- 当前状态：本地实现与回归验证已完成；未执行线上迁移、回填、提交或部署，等待发布授权。

## 2. 实施分解

### P01：固定统计口径与契约

状态：已完成（统计口径已固化到设计文档、服务字段和前后端类型）。

### P03：状态变更事件写入

### P04：统计服务与后端权限

## 3. 角色与权限基线

| 角色 | `task_completion:read` | `task_completion:view_all` | 默认结果 |
| --- | --- | --- | --- |
| admin | 是 | 是 | 组织总计、员工分组、个人明细 |
| designer | 是 | 否 | 仅本人完成统计和明细 |
| production | 是 | 否 | 仅本人完成统计和明细 |
| installer | 是 | 否 | 仅本人完成统计和明细 |
| sales/finance | 否 | 否 | 不增加新完成统计区 |
| 其他自定义角色 | 按管理员组合 | 按管理员组合 | 由后端权限决定 |

`task_completion:view_all` 必须依赖 `task_completion:read`，但两个权限都不加入价格/财务敏感冲突集合；响应字段仍然是非财务字段。

## 4. 主要风险与控制

| 风险 | 控制措施 |
| --- | --- |
| 把订单创建月份当成完成月份 | 只用订单完成状态日志或明细完成事件时间 |
| 明细设计/制作/安装重复或少算 | 以 `(task_type, order_item_id)` 作为工作单元键，最终交付明细另行 distinct |
| 任务换负责人导致历史数据漂移 | 事件记录负责人快照，不读取当前负责人回算历史 |
| 普通员工传 `employee_id` 越权 | 后端授权后强制覆盖/拒绝，不由前端隐藏作为安全措施 |
| 返工后仍计入已完成 | 取该项目/明细/阶段最后状态，要求查询时仍处于完成状态 |
| 旧数据没有事件时间 | backfill 标记，全部统计可核对；当月不伪造时间并输出数据边界 |
| 管理员接口返回价格 | 独立响应 schema 白名单，加入价格字段回归测试 |
| 统计拖慢驾驶舱 | 汇总与明细分离、批量查询、索引、分页，失败不阻塞现有驾驶舱 |

## 5. 不在本轮范围内

- 不改变订单、设计、制作、安装状态机和现有进度算法。
- 不改变订单级任务可见员工的业务规则。
- 不新增金额、成本、利润、件数、面积或绩效工资统计。
- 不将完成统计自动开放给销售、财务、资源或外协角色。
- 不删除历史任务、订单、订单明细、操作日志或外协记录。
- 不部署服务器，不直接修复或重算线上业务数据；迁移回填需单独执行发布清单。
