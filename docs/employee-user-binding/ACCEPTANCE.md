# EUB-P01 验收标准

## A01 数据约束

- [x] 迁移 SQL 仅新增 `employees.user_id` 的部分唯一索引。
- [x] 迁移前检查无重复的未删除员工绑定；发现重复时迁移明确失败且不改数据。
- [x] 升级和降级在隔离数据库演练通过。
- [x] 软删除员工不阻止同一账号绑定新的未删除员工档案。

## A02 绑定规则

- [x] 可绑定账号只包含启用、未删除且未绑定其他有效员工的用户。
- [x] 编辑员工时可以保留当前账号，也可以换绑或清空。
- [x] 停用账号、无效 UUID、不存在员工和重复绑定均返回明确中文提示。
- [x] 绑定/解绑接口只能由现有员工管理权限调用。

## A03 页面展示

- [x] 员工列表显示登录账号或“未绑定”。
- [x] 用户列表显示关联员工的工号、姓名、部门或“未关联员工”。
- [x] 新建员工保存后可继续绑定账号，不需要重新进入页面。
- [x] 绑定不会修改用户角色和权限，解绑不会删除任一侧档案。

## A04 既有业务不回归

- [x] 已绑定员工的设计、制作、安装任务执行和完成统计逻辑保持正常。
- [x] 未绑定账号仍按原规则登录，但不能被解析为普通任务执行员工。
- [x] 任务分配列表不出现未绑定/停用/离职员工。
- [x] 不修改订单、任务、工资、考勤和历史业务数据。
