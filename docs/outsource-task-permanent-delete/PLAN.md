# 外协任务永久删除实施计划

> 2026-10 修订 P06–P08 为当前执行范围，取代初版中“财务关联阻止删除”和“输入完整任务编号确认”的规则。P01–P05 中仍适用的付款保全、权限、审计与验证要求继续有效，其余冲突条款以本修订为准。

## 模式与范围

- 模式：STRICT。
- 风险：高；涉及不可逆数据删除、付款流水、角色授权与跨模块财务统计。
- 有界目标：永久删除回收站中的单条已取消外协任务，并在同一事务删除直接关联的外协付款、任务/付款日期核对和费用重叠审查；保留项目成本、订单/明细、内部任务与操作日志。
- 不做：生产数据清理、批量删除、删除项目成本或其他非直接关联财务数据、删除订单/明细/内部任务/操作日志、为旧数据补造付款日期。
- 预计不新增数据库表；需要新增权限码并提升权限种子版本。只有审计要求超出既有操作日志能力时才另行提出迁移。

## 执行项

### P01：保全软删除与恢复中的付款事实

- 调整软删除流程：只把任务移入回收站，不物理删除 `outsource_payments`。
- 调整恢复流程：保留可验证的付款明细和金额；没有付款明细但任务保留非零历史已付汇总时，不得静默重置为 0。
- 增加回归测试；不尝试自动恢复已被旧逻辑删除的付款行。
- 主验收：A01。

### P02：建立永久删除资格检查（按 P06 修订）

- 在服务层形成统一资格检查，返回可删除标记及阻止原因。
- 当前资格只检查任务是否位于回收站且状态为已取消；财务引用和历史已付汇总改为清理目标及删除影响，不再作为阻止条件。
- 在删除事务中重新检查，避免仅依赖前端预检结果。
- 主验收：A02。

### P03：实现独立权限、事务删除与审计

- 新增 `outsource_task:permanent_delete` 权限、依赖和角色种子版本；默认仅系统管理员获权。
- 新增独立回收站永久删除 API；服务端锁定任务并执行资格复核。
- 将最小必要任务快照、操作者、原因、时间、IP 写入现有操作日志；日志与删除同事务提交。
- 在同一数据库事务内显式删除直接关联付款、核对与费用审查，再删除任务；不得删除项目成本或业务主记录。
- 主验收：A03。

### P04：回收站资格提示和双重确认

- 为有权限用户展示永久删除入口及资格状态；阻止时显示可理解原因。
- 确认窗展示关联业务和将删除/保留的数据、不可恢复说明；删除原因必填，不再要求重复输入任务编号。
- 删除成功后刷新回收站；失败时保留上下文并显示后端阻止原因。
- 主验收：A04。

### P05：严格验证与发布门禁

- 覆盖服务、API 权限、并发/事务、历史付款清除审计识别、前端确认和财务汇总测试；更新原“删除时级联删除付款”的测试预期。
- 以隔离测试数据验证允许/拒绝场景；本次修改不触碰生产数据，不把生产演练或发布纳入本次执行。
- 生产上线前确认备份及恢复证据；部署后只做健康检查和只读功能核验。
- 主验收：A05。

### P06：原子清理直接关联的外协财务记录

- 在一个事务中删除外协付款、直接指向任务/这些付款的付款日期核对（含撤销记录）、指向任务的费用重叠审查，再删除任务。
- 保留项目成本及其核对、订单/订单明细、来源设计/制作/安装任务和操作审计；为永久删除日志保留最小必要的影响快照。
- 付款/核对/审查/历史已付金额不再构成阻止条件；仅回收站状态和“已取消”状态仍为强制条件。
- 主验收：A06。

### P07：简化并展示删除影响

- 移除任务编号重复输入；删除原因仍为必填 5–500 字。
- 弹窗列出来源内部任务、订单/明细和将被清理的财务记录数量/金额，并醒目标明项目成本及业务任务会保留。
- 主验收：A07。

### P08：回归与发布前验证

- 覆盖删除/保留范围、权限、事务回滚、审计、前端确认、并发复核和 expenditure 统计口径。
- 运行聚焦测试、类型检查、Lint、构建、安全和差异审查；不对生产数据执行删除。
- 主验收：A08。

### P09：用户授权提交、推送与生产发布

- 授权依据：用户于 2026-10-23 明确要求“提交推送部署”。
- 通过功能分支提交并推送，按受保护 `master` 的 PR 流程合并；不强推或改写历史。
- 发布目标：`192.168.0.102:/opt/adcraft`，使用仓库 `deploy.sh --branch master --commit <merge commit>`。
- 发布前回滚基线：`5bbaf9bacb02fc7c24fea0eb854cba92dd3dba47`；确认服务器工作区干净、配置可用及服务健康。
- 本次无数据库迁移、依赖变更或生产数据修改；部署后核对服务、数据库健康、日志及 `.deployed-commit`。
- 主验收：A09。

## 关键决策

- 永久删除仅处理回收站中状态为“已取消”的单条任务；付款、任务/付款日期核对和任务费用重叠审查会随任务清理，影响摘要进入删除审计快照。
- 项目成本（含其独立付款日期核对）、订单/报价、订单明细、内部设计/制作/安装任务及操作审计日志必须保留。
- 删除原因保持必填 5–500 字；任务编号只作展示，不要求再次输入。
