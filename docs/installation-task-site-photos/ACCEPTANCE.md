# 安装任务现场照片验收标准

## A-ISP-01 上传安全与兼容

- [ ] JPG/JPEG、PNG、WEBP 图片可以上传。
- [ ] 非图片、超过 10MB、签名与 MIME 不匹配的文件被拒绝。
- [ ] 不存在的安装任务不能创建附件。
- [ ] 安装照片保存为 `category=photo`，文件名不影响服务器路径安全。
- [ ] 历史图片附件仍能显示，非图片历史附件不被删除。

## A-ISP-02 拖拽和批量上传

- [ ] 可将图片拖到上传区域上传。
- [ ] 点击上传区域可以打开文件选择器。
- [ ] 可一次选择多张图片。
- [ ] 拖拽进入、离开和上传中有明确反馈。
- [ ] 同批次一张失败时，其余图片继续上传。
- [ ] 失败图片可以单独重试。

## A-ISP-03 缩略图和放大预览

- [ ] 上传成功后显示缩略图。
- [ ] 点击缩略图可以放大。
- [ ] 多张图片可以切换、缩放、旋转和关闭。
- [ ] 删除按钮需要确认，且不误触发预览。
- [ ] PC 页面在 1440、1024、390 宽度下不产生横向溢出。
- [ ] 手机安装页原有拍照、相册和预览行为不回归。

## A-ISP-04 质量和交付

- [ ] 前端单元测试通过。
- [ ] 后端上传校验测试通过。
- [ ] 类型检查、Lint、生产构建和后端测试通过。
- [ ] 不新增依赖、不新增数据库迁移、不改变任务状态和进度规则。
