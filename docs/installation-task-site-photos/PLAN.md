# 安装任务现场照片实施计划

## 任务分类

- 类型：跨前后端的文件上传交互增强。
- 模式：STRICT。涉及文件类型、大小、路径、权限和持久化附件。
- 风险：中等。核心业务表不变，但错误的文件处理可能造成越权、磁盘污染或历史照片不可见。
- 依赖预算：不新增依赖，不新增数据库迁移。

## 计划项

### ISP-P01：登记范围与上传安全契约

- 明确复用附件表和现有上传接口。
- 增加前后端允许类型、大小、签名和安装任务存在性校验。
- 固定安装照片分类为 `photo`，兼容历史图片附件。

对应验收：A-ISP-01。

### ISP-P02：实现拖拽上传区域和上传队列

- 在现场照片卡片中增加拖拽/点击上传区域。
- 支持批量选择、限流上传、单张失败不阻断其他图片。
- 展示上传中、失败和重试状态。

对应验收：A-ISP-02。

### ISP-P03：实现缩略图和放大预览

- 以网格展示图片缩略图。
- 使用现有 UI 库图片查看器支持放大、多图切换和关闭。
- 保留删除动作并避免删除按钮触发预览。

对应验收：A-ISP-03。

### ISP-P04：测试、质量验证与交付准备

- 增加前端文件校验和后端上传校验测试。
- 执行前端测试、类型检查、Lint、构建和后端全量测试。
- 检查差异范围、敏感信息和无迁移/无依赖约束。

对应验收：A-ISP-04。

## 不纳入本期

- 安装前/安装中/安装后分类。
- 照片水印、GPS、备注、排序和批量删除。
- 服务端缩略图服务。
- 任务状态、任务进度、验收和订单明细规则调整。

## 后置 backlog

- ISP-B01：现场照片阶段标签。
- ISP-B02：服务端生成缩略图和对象存储迁移。
- ISP-B03：照片备注、定位和安装明细关联。
