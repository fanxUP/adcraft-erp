# 安装任务现场照片设计

## 目标

在安装任务详情页的“现场照片”卡片中提供拖拽/点击批量上传、上传状态、缩略图展示和点击放大预览。继续复用现有 `attachments` 表和安装任务详情接口，不改变任务状态、进度和订单明细逻辑。

## 当前基础

- `InstallationTaskDetail.vue` 已有单按钮上传和照片网格。
- `InstallationTaskResponse.attachments` 已返回附件记录。
- `/api/v1/attachments/upload` 已支持 `installation_task` 关联。
- 手机安装页已经有拍照、相册和图片预览，本期保持其行为不变。

## 交互设计

1. “现场照片”卡片内增加虚线拖拽上传区域，支持拖入多张图片和点击选择。
2. 上传区域显示格式、单张大小和批量数量提示；拖拽进入时高亮。
3. 图片先经过前端校验，再进入上传队列；同时最多上传 3 张。
4. 上传成功后使用固定尺寸网格展示缩略图；上传中、失败和重试状态均可见。
5. 点击缩略图进入 Element Plus 图片查看器，支持切换、缩放、旋转和关闭。
6. 删除照片仍走现有附件删除接口，删除按钮不触发图片预览。

## 数据和安全边界

- 使用 `related_type=installation_task`、`category=photo` 关联现有附件表。
- 安装照片仅允许 JPG/JPEG、PNG、WEBP，单张不超过 10MB。
- 服务端再次校验 MIME、文件签名、文件大小和安装任务存在性，不能只依赖浏览器 `accept`。
- 使用按 MIME 映射的安全扩展名生成文件名，不采用用户原始文件名作为路径。
- 不新增表、不新增依赖、不自动推进任务状态、不新增照片分类和水印。

## 兼容性

- 已有图片附件继续显示；分类缺失但 `file_type` 为图片的历史附件也兼容显示。
- 非图片历史附件不进入新的照片网格，不删除数据库记录。
- PC 页面增加拖拽能力；手机端保留原有拍照/相册入口和预览逻辑。
