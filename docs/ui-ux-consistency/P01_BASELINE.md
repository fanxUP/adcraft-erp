## 1. 本阶段结论

P01 已完成代码结构盘点和核心流程真实页面采集，形成了后续 UI/UX 全栈改造的范围基线。

订单 O20260817-0001 的台签纸已进入安装完成，铜板纸彩印仍处于安装中；订单详情按明细展示了独立总进度和阶段进度，符合用户要求的“两层关系”在设计/制作/安装阶段生效。

## 7. 规范冻结决策

P01 冻结以下规则，后续实现不得自行改变：

- 默认视觉基线采用当前蓝色浅色商务主题；移动端暗色主题是否保留，必须经过对比度和现场可读性验收。
- 工作台和项目看板共享同一任务卡结构、同一进度值和同一终态隐藏规则。
- 订单明细是设计、制作、安装任务的最小可操作对象；“完成任务”不能回到整单批量更新。
- 状态标签、进度条和不可操作原因由统一视图模型提供，页面不再自行猜测。
- 前端只负责显示能力结果，后端继续作为权限、状态、金额和并发的最终事实来源。
- 不新增审核人员、不接入短信/邮件/飞书、不恢复用户已经要求删除的历史审核模块、任务依赖或验收信息。
