# UIX-P07 实施证据：资源、AI、人事与系统模块迁移

## 1. 结论

UIX-P07 已完成。本阶段将资源、高空作业车、AI、人事、系统管理和外协辅助页面迁移到已在 P05/P06 验证过的统一页面骨架与反馈模式，同时保留矩阵、报表、卡片、照片和移动安装等业务专用布局。

本阶段没有修改 API URL、数据库模型、迁移、存储、通知、部署脚本或依赖清单，也没有改变车辆调度、考勤、工资、AI 草稿、外协或备份操作的业务规则。服务端已有的 `status_view`/`capabilities` 仍是通用业务对象的优先语义来源；资源专用状态在接口尚未提供 canonical 视图的地方保留原有领域映射，并没有把前端映射当作授权。

## 2. 本阶段交付

### 2.1 资源与高空作业车

- 车辆、司机、调度、用车申请、出车/收车台账、车辆异常统一使用 `AppPage`、`PageHeader`、`PageToolbar`、`DataTableShell` 和可重试错误状态。
- 高空车档案、人员、每日出车台账、人员垫付/报销、人员工资、车辆费用、安全检查、Agent 草稿和统计报表统一页面标题、筛选层级、分页与反馈；高空车统计中的金额改用共享 `formatMoney`。
- 库存列表和库存出入库记录复用同一列表状态壳层；修复切换到“出入库记录”后没有主动加载记录的问题。
- 车辆/高空车的考勤矩阵、报表汇总和复杂结算弹窗保留原有业务布局，只统一页面外层标题与操作位置。

### 2.2 AI 页面

- AI 模型中心的供应商卡片网格、模型列表保留其领域信息密度，但统一供应商/模型列表状态、筛选工具栏和重试反馈。
- AI 报价助手、异常分析、付款 OCR、业务叙事报告、报价知识库、现场照片识别和 Agent 草稿中心接入统一页面标题；草稿列表增加标准的加载、空态和错误重试状态。
- AI 写操作仍由既有页面与后端接口确认，页面上的禁用/隐藏只作为能力提示，不替代权限校验。

### 2.3 人事与考勤

- 员工、部门、员工履历、请假、考勤规则、工资规则和工资表统一标题、筛选操作区、列表/矩阵外层间距与错误反馈。
- 考勤表和工资表的横向矩阵、汇总卡片、单元格编辑和打印预览保持原有交互，不强行改成普通表格，避免损失业务信息密度。
- 人员垫付、工资和车辆费用金额统一使用 `formatMoney`，空值与小数显示不再由页面自行拼接。

### 2.4 系统与外协辅助页面

- 用户、角色权限、系统设置、通知、操作日志和备份管理统一页面标题、列表状态和操作反馈；角色/备份加载失败支持显式重试。
- 外协商、外协任务回收站与外协付款页面统一金额、分页和列表反馈；恢复、删除、备份恢复等敏感操作继续保留确认步骤。
- 移动安装页保留移动端底部抽屉、拍照、上传和下拉刷新布局；其错误、空态和提交中状态仍由移动专用交互承载，没有用桌面表格替代。

### 2.5 一致性契约与缺陷修复

- 新增/扩展 `resource-admin-ui-cleanup.test.ts`，约束资源、AI、人事、系统和外协页面复用共享壳层，约束矩阵/报表/AI 专用页至少复用 `AppPage` 与 `PageHeader`。
- 修复供应商页状态变量命名不一致，将 `providerTableState` 收敛为列表契约约定的 `tableState`。
- 清理标题迁移后遗留的 `Calendar`、`Money` 无用图标导入，Lint 不再报告死引用。
- 页面中既有的领域状态标签未在没有服务端 canonical 字段的接口上擅自重构，避免 UI 一致性改造改变业务状态事实。

## 4. 范围与审查

### 4.1 范围预算

- 当前复合工作树实测为 100 个已跟踪变更文件、35 个新增文件；低于 P07 的 160 个变更文件、55 个新增文件上限。
- 变更集中在资源、高空车、AI、人事、系统、外协辅助页面、共享 UI 测试和阶段证据文档；P01-P06 的历史未提交变更按范围锁保留。
- 未修改 API URL、数据库表/迁移、存储、通知渠道、部署脚本、依赖清单或 lockfile。

### 4.2 质量与安全审查

- 列表页统一区分 loading、empty、error 和 ready；可恢复的加载失败提供显式重试入口。
- 统一金额格式只影响展示，不改变金额计算、结算、工资核算或备份恢复事实。
- 备份恢复、删除、外协恢复/删除和工资发放等敏感写操作继续保留原有确认/权限边界。
- 前端状态标签和禁用状态不作为最终授权；后端现有校验继续负责权限与业务事实。

## 5. P08 边界
