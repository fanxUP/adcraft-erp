# 实施计划：财务历史核对闭环

| Plan ID | 工作项 | 主验收项 |
|---|---|---|
| P1 | 增加核对记录模型与非破坏性数据库迁移；约束核对金额、证据、操作者与撤销信息 | A1 |
| P2 | 实现并发安全的付款日期分配、撤销、疑似重复复核 API；把已核实分配投影进日期付款并从未核实余额扣除 | A2 |
| P3 | 在财务总览中提供历史付款核实表单、疑似重复复核表单和原业务记录入口 | A3 |
| P4 | 完成迁移、权限/金额/日期/回归测试、安全审查和正式质量门；本任务只交付本地已验证代码 | A4 |

## 依赖图

P1 → P2 → P3 → P4

## 交付界限

本轮交付为本地已验证代码；提交、推送和线上部署须在用户单独授权并完成发布预检后进行。
