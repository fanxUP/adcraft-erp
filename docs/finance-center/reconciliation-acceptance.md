# 验收标准：财务历史核对闭环

- **A1 / P1**：迁移仅创建核对表、必要的检查约束和索引；模型与 Alembic metadata 一致。核对记录可追溯、不可物理删除。
- **A2 / P2**：凭证支持的付款日期分配按实际日期进入付款视图；部分核对保留未核实余量；分配不增加来源累计已付。金额超额、来源无效或已软删除、证据缺失、未来日期、重复核对和并发竞争均有回归测试。撤销带原因且恢复未核实余额。疑似重复复核只记录判定，不改变业务金额或来源。
- **A3 / P3**：前端可找到日期待核实付款及疑似重复候选，录入证据参考、金额、实际日期或复核结论，并能跳转到原业务模块；保存后汇总/状态刷新，显示不自动改账的提示。
- **A4 / P4**：迁移在一次性隔离 PostgreSQL 测试库中升级与降级成功；后端全测、前端单测、lint、typecheck、build、范围/预算/安全/回归和质量门通过；工作树 diff 不含无关修改；无生产数据操作。
