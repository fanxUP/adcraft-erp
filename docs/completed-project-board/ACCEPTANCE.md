# CPB-P01 验收标准

## 后端

- [ ] 未拥有 `task_completion:read` 的账号调用完成项目列表/详情返回 403。
- [ ] 普通员工只能看到自己作为 `assignee_user_id` 完成过明细的项目，不能通过参数查看其他员工项目。
- [ ] 普通员工详情只包含自己的完成明细；不同阶段没有读取权限时不返回该阶段事件。
- [ ] 拥有 `task_completion:view_all` 且满足依赖的账号可以查看权限范围内的全部完成项目和明细。
- [ ] 当前订单不是 `completed`、最新订单日志不是 `completed`、订单已删除或已取消时不出现在完成列。
- [ ] 同一阶段/明细只取最新事件；完成后返工的明细不计入当前完成结果。
- [ ] 没有价格权限的响应不包含 `total_amount`；任何完成项目响应不包含单价、小计、成本、利润或外协字段。
- [ ] 分页数量、项目卡片去重、详情不存在/越权错误契约稳定。

## 前端（CPB-P01）

- [ ] 独立项目看板存在第四列“完成”，每个项目只显示一张卡片。
- [ ] 工作台项目看板和独立项目看板均通过完成项目 API 加载，不复制另一套筛选逻辑。
- [ ] 完成卡片显示项目基础信息、完成数量/阶段和完成时间，并可打开只读详情。
- [ ] 完成卡片可打开只读详情，且不显示状态变更、改派、编辑、删除、恢复操作。
- [ ] 无完成统计权限的账号不请求完成项目 API，也不显示完成列；活跃任务列仍正常加载。
- [ ] 完成 API 失败时只显示完成列的空/错误状态，不阻塞其他看板。

## 独立完成详情页（CPB-P02）

- [x] 工作台和独立项目看板的完成卡片都跳转到同一个独立完成详情路由。
- [x] 完成详情不再以抽屉形式打开，旧抽屉组件没有任何运行时引用。
- [x] 工作台完成统计区不再渲染完成项目/完成明细表、阶段明细筛选和分页；只保留汇总摘要。
- [x] 独立详情页显示项目编号、项目名称、客户名称、部门/科室、完成时间、可见订单金额和完成明细表。
- [x] 详情页加载中、加载失败、无明细和金额无权限时都有稳定的展示状态；失败时不保留上一次项目数据。
- [x] 路由守卫要求 `task_completion:read`，后端详情接口仍是最终的数据范围和字段权限边界。

## 回归

- [ ] 既有活跃任务看板仍隐藏已完成、已取消和 100% 任务。
- [ ] 既有任务明细按勾选项推进、明细执行人归属和价格脱敏测试不回归。
- [ ] 后端相关测试、前端 Vitest、typecheck 和 build 全部通过。

## CPB-P03：完成项目详情按明细重排与资料区

- [x] 管理员详情主表一条有效订单明细只出现一行，并按订单 `sort_order` 排列。
- [x] 主表列顺序固定为项目内容、产品/材质/工艺、规格、数量、设计、制作、安装；规格不显示空值/0 尺寸，数量带单位。
- [x] 每个阶段只显示该阶段/该明细的最新完成事件；一个明细在不同阶段的执行人互不覆盖，不能复用任务级负责人造成串名。
- [x] 阶段单元格按“状态、执行人、完成时间（年月日）”三行显示；后端回退/返工后不显示失效的旧完成信息。
- [x] 设计、制作、安装三个资料区按任务编号分组；设计/制作支持图片缩略图、放大、视频播放、文件类型/大小/上传时间、预览或下载；安装只显示现场图片和视频。
- [x] 员工与管理员的项目、阶段、任务、执行人和附件范围继续遵守现有权限；没有阶段读取权限时响应不包含该阶段任务和附件信息。
- [x] 完成详情保持只读，不新增上传、删除、改派、状态变更或价格字段；不出现内层固定高度滚动容器。
- [ ] 后端查询不产生订单明细/任务/附件的 N+1 请求，后端相关测试、前端契约测试、typecheck、lint、build 和门禁检查通过。

> 说明：后端资源查询已按项目批量加载订单明细、任务和附件，相关测试及前端检查均已通过；最后一项保留未勾选，是因为当前工作区没有可执行的 Vibe 自动门禁脚本，未将手工等价检查冒充为自动门禁通过。
