# 公司账户与付款账户实施

目标：展开登记支出的付款方式、说明和凭证；财务中心增加公司账户；按每次付款记录付款账户。保留现有数据来源、金额和权限边界，不实现银行余额、收入、调拨或自动历史回填。

- P1 / A1：新增账户主数据、独立选择/读取/管理/查看完整账号权限、默认及启停规则；被使用的账户身份不可改、不可删除。
- P2 / A2：支出和项目成本登记时已付、应付后续付款、外协付款分别关联账户；新增实付必须选择启用账户；备注和凭证编辑兼容历史空账户。
- P3 / A3：公司账户列表和表单、公共账户选择组件、所有付款入口、付款记录账户显示/筛选/补录；付款统计复用有效付款查询，标明已登记付款合计。
- P4 / A4：真实隔离 PostgreSQL 验证迁移及金额核对、分批付款、停用、补录、权限和删除规则；前端类型/构建及相关回归检查。

迁移：新增账户表和四处可空账户外键，无历史更新。锁风险为新增列/FK/index所需短时表锁；上线前设置 lock_timeout 并备份，先在隔离测试库演练。回退应用可保留新增结构；已有账户数据时拒绝破坏性 downgrade，需协调导出恢复。开发验证不操作生产数据库。

验收：相同权限/日期范围下，已分配账户的有效付款之和加未登记账户付款等于全部有效付款；原业务总额、已付和待付不变。无新增依赖。
