# 任务详情优化（两轮）

目标：设计、制作、安装共用紧凑概览、按订单分项折叠的明细处理、资料及外协区域。

## 实施范围

1. 后台返回任务删除的实际关联目录、订单状态回退、下游任务、移入回收站的验收单、解除来源的外协记录；详情弹窗确认，提交时校验影响指纹。保留既有删除语义与权限；不执行历史数据修复。
2. 完成动作统一由资料弹窗确认，成功后关闭；失败保留文件。状态、改派、外协发送和复核后统一刷新关联区域。
3. 概览突出项目、状态与进度，联系方式折叠；安装地址保持醒目。
4. 明细按既有分项分组，待处理组默认展开；支持关键词、任务范围、状态、我的明细筛选，按需展示价格列，选中后显示改派。
5. 资料支持按明细折叠；外协记录支持分页与加载失败提示。补全详情首次加载/失败反馈，统一返回与删除权限。

## 验收

- 删除预览匹配现有三个阶段的条件级联；无删除权限不能预览；影响变化拒绝旧指纹。
- 模拟完成失败后弹窗/文件保留，成功后关闭；外协发出后明细重新读取。
- 分项同名不同 ID 不合并、未分项保留；筛选不改变业务数据，改派始终提交明确选中的明细 ID。
- 运行有针对性的后端回归、前端单元检查、ESLint、类型检查与构建。

## 范围与后续

不新增依赖、迁移或数据存储。新建 1 个删除预览接口，3 个删除接口增加可选影响指纹（兼容既有调用）。本轮不提交、不部署，等待用户发布指令。
详细订单变更前后差异、资料版本管理、完整操作时间线留待第二轮。

## 第一轮完成情况

- 三类详情页共用紧凑概览和分项明细处理；关键安装信息常驻；筛选、价格按需展示、勾选后改派、资料折叠已完成。
- 删除影响目录展示订单状态回退、删除的各阶段任务、可展开的关联明细、任务附件数量、验收单及外协来源解除；无对应查看权限的关联编号隐藏。确认时重新读取关联状态与指纹。

## 第二轮实施范围

1. 新增一个只读、分页的任务活动接口，聚合本任务操作日志、明细状态日志、订单变更快照、本阶段资料增删及可见外协记录。保持任务类型读取权限及订单员工可见范围，字段白名单过滤；价格仅有订单价格权限时返回。
2. 三类详情共用活动卡片，默认收起，展开时加载；支持全部/订单变更/执行记录筛选。订单快照按当前及历史关联明细 ID 比较，呈现字段前后值；复核按钮可定位变更记录。
3. 同阶段、同明细、同文件名展示上传历史并标出最近上传，时间缺失或相同则不指定唯一最近；不推断已确认版本，不覆盖或删除旧文件。
4. 时间线保留未知时间，旧明细日志的上海业务时间转换为 UTC 后排序；缺失历史事实不补造，已有审计未记录的具体改派前后人名不推测。

本轮新增 1 个只读接口，无依赖或迁移。累计预算调整为 24 个变更文件、8 个新文件、5 处兼容 API 变化。生产发布仍等待明确指令。

## 外协分配合并到订单明细

用户已批准“一张订单明细主表＋行内外协操作＋外协记录弹窗”方案，本轮在本地实施。

- 三类详情页只保留原明细主表，移除独立外协分配表和已发送外协表；删除原 `OutsourceTaskCard`，发送表单和记录弹窗由 `TaskOutsourceDialogs` 共用。
- 项目与产品/材质/工艺放在同一格，当前阶段与本任务状态同格显示；每条明细保留执行人、独立进度条和现有状态操作。销售价格与外协成本分别标注，按各自权限显示。
- 按明细 ID 对应当前任务的分配摘要，直接显示外协状态、有效记录数、已分配和剩余可分配数量；行内发送/追加外协，默认剩余数量，超量原因必填。缺少供应商读取权限时禁止发送；供应商目录按需分页读取，并过滤承接类型。
- 行内数量、计划及已确认成本按当前来源任务统计，任务阻塞仍沿用后台“同订单＋同明细＋同阶段所有来源未完成外协”规则。阻塞明细默认打开全部来源记录，其余明细默认本任务；弹窗可切换范围、分页、重试，并区分本任务/其他来源/历史未记录来源。其他来源任务链接继续受任务读取权限控制。
- 历史整单外协单独提示、计价和查看，不分摊到明细；取消/删除的分配释放规则以及销售、成本、实际付款的核算规则沿用现有接口。

- 所有信息仍直接显示，未增加折叠。桌面使用九列主表，窄内容区沿用两列/单列布局。
