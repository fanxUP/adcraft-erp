# 统一订单改造实施与验收报告

本轮按已确认方案完成本地实现。订单可直接创建，在待确认、执行中、已完成阶段统一编辑；取消订单先恢复再编辑。本轮没有提交、推送、部署或写入生产数据库。

## 已交付行为

| 业务 | 修改后的行为 |
|---|---|
| 创建订单 | 订单管理直接新建，沿用分组、产品选择、计价、Excel导入、优惠与税率；保存为待确认，确认后安排执行。客户端不能指定服务端合计。重复请求返回同一次创建结果；重复确认订单不重复派工。 |
| 编辑订单 | 使用同一个完整编辑页；提交前展示明细差异、金额变化及关联目录，使用版本校验和有时效的确认凭据。已完成订单也可修改。 |
| 执行任务 | 当前需求刷新，原进度和负责人保留；完成范围保留快照。只改售价不重开任务，新增范围单独补做；连续追加不会重复派发历史数量。未知部分完成量不按百分比猜测。 |
| 外协 | 未执行且计价、范围能明确映射时刷新计划；销售单价不会覆盖采购单价。固定总价、部分范围及已付款差异保留原值并生成处理事项。已执行、已结算记录不覆盖。 |
| 验收与合同 | 可明确映射的草稿内容刷新；已验收的单行、整单验收及已签合同保留原值，生成补验、补签等处理事项。 |
| 收款与退款 | 直接订单无需合同也能登记实际收款；降价到实收以下显示超收/待退。退款增加引用原凭据的负向流水，原收款金额和日期保持不变。 |
| 合同预收 | 超收转合同预收及预收重新分配使用成对的分配冲回记录，现金流和合同净收守恒。存在退款或分配冲回的原凭据不能直接作废。 |
| 对账与报表 | 草稿对账随订单、资金变化刷新，无资金订单更正客户时同时刷新原、新客户对账，已确认对账保留明细快照。独立订单进入应收和欠款排行；待确认订单排除实际收入/应收；取消订单的真实款项与最终结算余额保留。 |
| 删除与恢复 | 删除前列出关联项并确认最终结算金额、原因；移入回收站，停止未执行工作。只恢复本次取消的内部任务、草稿验收及未付款外协，不复活此前已取消的记录。原资金、成本和完工事实保留。 |
| 变更闭环 | 详情页增加变更与资金处理；需外部确认的差异持久化，有负责人、状态和处理凭据。任务页面复核会关闭对应复核事项；资金差额实际处理后关闭超收事项。 |
| 历史与智能入口 | 日常报价入口退役，旧报价链接只读，新建链接转订单。报价写API返回410。AI保存及图稿采集草稿改为订单，历史报价按来源幂等继续处理为订单；归属不明确的历史成本/合同关联阻止自动复制。 |
| 历史报价成本 | 默认成本列表查看订单；历史报价成本保留查询，停止新登记、导入及修改成本内容。原应付付款事实沿用独立财务流程。 |

计价规则复用现有服务端计算：有效明细小计－优惠＋税额＋结算调整。待收与超收分别取正值，不用负数欠款代替待退款。

## 页面验收样本

在独立本地数据库及测试身份下实际操作，没有写入真实客户业务、发起真实转账：

1. 新建10件×100元，优惠100元，总额900元；保存待确认、确认后生成设计任务。
2. 登记实际收款800元；重新打开编辑页仍保留优惠100元。
3. 单价改80元，总额700元；关联弹窗只列实际单价变化，设计任务关联、负责人和进度保留，显示超收100元。
4. 登记实际退款100元，原800元收款与新增－100元退款并存，超收事项自动关闭。
5. 按最终结算700元删除，回收站仍可查两笔流水；恢复后订单为设计中，总额700元、净收700元、待收0元。
