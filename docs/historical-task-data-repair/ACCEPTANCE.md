# 历史任务异常数据修复验收标准

本文件与 `PLAN.md` 的 HTR-P01 至 HTR-P07 一一对应。H-001 和本次 H-002 已按本验收标准执行并完成线上验证；其余候选仍处于人工复核或历史保留状态。

## A-HTR-01：范围和状态不变量

对应：HTR-P01

- [x] 修复范围仅包含设计、制作、安装任务链及其订单阶段状态。
- [x] `rolled_back`、`cancelled`、当前有效关联和历史日志可以明确区分。
- [x] 旧整单任务缺少逐条证据时显示历史未记录，不伪造明细状态或执行人。
- [x] 财务、权限、附件物理文件和员工资料没有被本批次改写。

## A-HTR-02：只读审计器

对应：HTR-P02

- [ ] 默认运行不写入任何业务表。
- [ ] 能检查订单、有效明细、任务卡、明细关联、状态日志和外部引用。
- [ ] 能输出重复卡、回退重入、订单状态差异、旧整单未知范围和历史日志保留等分类结果。
- [ ] 脚本在当前线上数据库执行时有超时/错误退出保护，不影响应用服务。

## A-HTR-03：候选干跑

对应：HTR-P03

- [x] H-001 的来源完成事件晚于目标制作回退事件，并列出拟变更字段。
- [x] H-003 不被误判为可重入；H-002 经重新审计后按“设计关联状态滞后”单独纠偏。
- [x] H-004/H-005/H-006/H-007 被列为人工确认或历史保留，不自动进入写入队列。
- [x] 干跑二次输出的候选分类和拟变更集合保持一致。

## A-HTR-04：确定性阶段重入

对应：HTR-P04

- [x] 只修改授权明细，不修改同任务卡其他明细。
- [x] 目标关联从 `rolled_back` 恢复为该阶段等待状态，进度为 0，完成时间为空，当前执行人为空。
- [x] 不产生重复任务卡或重复有效关联。
- [x] 修复事件、操作审计和前后快照完整。
- [x] 重复执行返回幂等结果，不重复写入业务事实。
- [x] 任一步失败时事务整体回滚，来源和目标不出现半成功状态。
- [x] H-002 只恢复设计关联为 `pending/0%`，没有把制作关联从 `rolled_back` 提前恢复。

## A-HTR-05：订单状态同步

对应：HTR-P05

- [ ] 在修改 H-006 前，已明确安装完成与订单完成的业务规则及验收边界。
- [ ] 只有所有有效明细的三阶段事实满足规则时才允许同步订单状态。
- [ ] `O20260819-0001` 不因历史完成日志被自动恢复或标记完成。
- [ ] 订单状态变更通过服务层并写入正常订单状态日志。

## A-HTR-06：重复任务卡治理

对应：HTR-P06

- [ ] 合并前有明确的保留卡和重复卡清单。
- [ ] 明细、附件、操作日志、状态日志、外协和车辆引用数量前后一致。
- [ ] 已取消历史卡默认保留，不因界面显示问题直接物理删除。
- [ ] H-004/H-005 未经单独授权不执行合并或删除。

## A-HTR-07：修复后质量与回滚

对应：HTR-P07

- [x] 修复前有可识别的数据库备份引用，并已确认恢复路径。
- [x] 修复前后快照可以逐字段对比，影响范围与授权范围一致。
- [x] 有效明细关联无重复、进度与状态一致、订单阶段没有误推进。
- [ ] 任务完成统计、项目看板和完成项目详情没有重复计数。
- [ ] 附件数量、文件路径和下载/预览能力不受影响。
- [x] 重新审计后，已处理项为已解决/幂等，未处理项均有明确原因。
