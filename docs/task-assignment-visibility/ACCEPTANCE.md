# TAV-P01 验收标准

## A01 数据与默认行为

- [x] 新增订单任务可见范围关联表，订单与员工唯一约束和查询索引齐全。
- [x] 空关联表示全员可见；不回填历史订单。
- [ ] 在隔离数据库执行 `upgrade` / `downgrade` 演练并留存日志。

## A02 任务入口权限

- [x] 设计、制作、安装角色保留工作台和详情能力。
- [x] 三类任务列表需要各自 `*:list` 权限，执行角色默认无列表权限。
- [x] 任务详情读取不依赖任务列表权限。
- [x] 订单详情按实际阶段列表权限分别请求数据。

## A03 订单级任务可见范围

- [x] 管理用户可以多选员工并保存订单任务可见范围。
- [x] 不选择员工时所有拥有对应任务详情权限的员工可见。
- [x] 选择员工后，只有被选员工可见工作台任务、任务详情、订单明细选项和任务附件。
- [x] 停用、离职、删除或未绑定登录账号的员工不能被新分配。

## A04 负责人维护与状态归属

- [x] 负责人维护接口仅需要对应 `*:assign`，不错误依赖通用任务编辑权限。
- [x] 无分配权限用户看不到可编辑负责人选择器。
- [x] 无分配权限用户提交其他负责人时由后端拒绝。
- [x] 无分配权限用户状态变更记录当前登录绑定的在职员工。
- [x] 未绑定在职员工时返回大白话错误提示。

## A05 外协信息隔离

- [x] 没有 `outsource_task:read` 时，任务详情不显示外协卡片、外协标签、编号或阻断原因。
- [x] 后端任务响应和订单明细选项不泄露外协状态字段。

## A06 价格隔离保持不回归

- [x] 设计、制作、安装任务响应和订单明细选项继续按既有价格权限裁剪金额字段。
- [x] 新增任务可见性查询不绕过既有价格字段裁剪。

## A07 自动化验证

- [x] 后端全量测试通过：1079 passed；仅有依赖弃用提示。
- [x] 前端全量 Vitest、类型检查、Lint、生产构建全部通过。
- [x] TAV 专项权限、可见性、路由和状态归属测试已加入。
- [ ] 浏览器按 1440、1024、390 宽度完成核心路由真实回归（需在迁移并发布后执行）。

## A08 发布安全

- [x] 本轮不部署服务器，不修改线上业务数据。
- [ ] 发布前完成数据库备份、迁移 dry-run 和角色冒烟。
- [ ] 发布后验证旧任务默认可见、指定员工可见、无权用户 404/403 行为和外协脱敏。
