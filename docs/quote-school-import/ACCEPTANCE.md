# 学校清单报价导入验收标准

| 计划 | 验收项 |
| --- | --- |
| P01 | 原始清单识别 16 所学校、174 条有效明细；汇总行不进入报价；必填数据缺失时预览阻断。 |
| P02 | `m2/㎡/m²/平方米/平米` 识别为面积；面积数量等于源数量；件数、长度、体积、重量不误判为面积；小计与数量乘单价一致。 |
| P03 | 正常提交生成 16 张草稿报价；同客户、同项目、同学校已有报价时阻止提交；任意失败不产生部分写入。 |
| P04 | 报价列表可上传、预览和确认；客户名称、项目名称可见；学校摘要金额与后端一致；导入期间按钮有明确加载状态。 |
| P05 | 后端测试、前端测试、Lint、TypeScript、Build、Git diff 检查通过；部署后服务、健康接口和关键 API 验证通过。 |
