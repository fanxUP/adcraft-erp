# 学校清单报价导入计划

## P01 清单解析和预览

读取固定表头，清洗文本、识别汇总行、校验数量/单位/单价，并按学校生成预览摘要。

## P02 显式面积和金额计算

让显式面积数量使用 Excel 数量参与计价，同时保持几何面积模式的既有行为。统一使用 Decimal 和两位小数金额。

## P03 报价批量提交

新增预览和提交接口。提交时按客户、项目、学校生成报价草稿，检查重复报价并使用一个请求事务完成整批写入。

## P04 报价列表导入入口

在报价列表增加学校清单导入弹窗，展示 16 所学校的明细数量、面积明细数量和金额，只有预览通过后才允许提交。

## P05 回归和发布验证

覆盖解析、面积识别、金额核对、权限、重复冲突、失败回滚、前端类型检查、构建和部署后健康检查。
