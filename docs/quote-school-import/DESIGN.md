# 学校清单报价导入设计

## 目标

将“学校文化阵地建设清单.xlsx”按学校拆分为报价草稿。客户名称和项目名称由导入表单统一注入，学校写入报价的“部门/科室”，一行清单明细对应一行报价明细。

## 数据规则

- 清理学校名称等文本的首尾空格和制表符，保留产品/材质/工艺中的有效换行。
- 跳过空行和“项目内容=合计、部门为空”的汇总行。
- `数量`直接映射为报价明细数量，`单价`允许为零，不能把零当成缺失。
- `m2`、`㎡`、`m²`、平方米、平米识别为显式面积数量。面积直接取 Excel 的数量，不从规格文本重新推算宽高。
- 块、个、组、樘、张按件数处理；m 按长度、m3 按体积、t 按重量处理。
- 小计由系统按数量或显式面积数量乘单价重新计算，金额保留两位小数。
- 备注写入明细备注；合并备注按其覆盖行保留，避免丢失。

## 写入边界

导入只创建报价草稿，不创建订单、任务或成本。提交前必须经过预览，提交时校验文件指纹、客户/项目参数和同客户同项目同学校的已有报价。冲突或任何一张报价失败时整批回滚。

## 兼容性

显式面积数量复用现有 `quantity_mode=area` 和 `area` 字段，不新增数据库迁移。几何面积开关仍表示“宽 × 高 × 件数”，与 Excel 已给出的面积数量分开。
