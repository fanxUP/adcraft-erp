# 工作台员工完成统计入口卡片与独立统计页设计

## 目标

将经营驾驶舱中展开的“员工完成统计”改为紧凑、可点击的入口卡片，详细统计移动到独立的完成统计页面，降低工作台高度并保留现有统计口径与角色隔离。

## 现状

`DashboardView.vue` 已请求完成统计汇总，但管理员会在页面内直接展开员工列表。现有后端已经提供 `/reports/task-completion/summary` 和分页明细接口，且已有 `task_completion:read`、`task_completion:view_all` 权限。

## 方案

- 工作台保留项目完成、完成工作明细、阶段分布等 KPI。
- 员工列表替换为一张入口卡片：管理员显示全员摘要，普通员工显示本人摘要。
- 点击卡片进入 `/reports/task-completion`，并透传当前 `period=month|all`。
- 独立页显示 KPI、管理员员工统计表、按项目/按明细列表、阶段筛选与分页；普通员工不显示员工表和员工筛选器。
- 不新增侧边栏菜单，入口来自工作台；直接访问仍由 `task_completion:read` 路由权限拦截。

## 数据与权限

页面复用现有汇总和明细服务，服务端继续按完成事件最新状态、任务可见范围和员工归属裁剪数据。普通员工只能查看本人；拥有 `task_completion:view_all` 且满足依赖的账号可以查看全员。所有统计响应继续为非财务字段。

## 非目标

- 不修改订单/任务状态机、完成事件写入、完成项目看板和数据库。
- 不增加金额、成本、利润、导出、编辑或新的权限码。
- 不在工作台保留员工姓名列表或复制一套统计查询。
