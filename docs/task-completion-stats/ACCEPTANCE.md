# 工作台员工完成统计入口卡片验收标准

## A01 工作台卡片

- [x] 工作台不再渲染员工姓名列表和展开式员工统计区。
- [x] 管理员看到全员完成摘要，普通员工只看到本人完成摘要。
- [x] 卡片高度紧凑，显示完成工作明细和设计/制作/安装摘要。
- [x] 当月/全部切换后卡片数据同步，点击整卡进入统计页。

## A02 独立页面

- [x] `/reports/task-completion` 可以从卡片进入并恢复统计范围。
- [x] 页面有返回工作台入口，并有加载、空数据、错误重试状态。
- [x] 无 `task_completion:read` 的账号不能通过直接地址进入。

## A03 统计内容

- [x] 管理员看到组织 KPI、员工统计表和全员/指定员工明细。
- [x] 普通员工只看到本人 KPI 和本人完成明细，不出现员工筛选器。
- [x] 支持按项目/按明细、设计/制作/安装筛选和分页。
- [x] 明细显示订单编号、项目、订单明细、阶段、任务编号、完成执行人和完成日期。

## A04 权限与数据安全

- [x] 普通员工不能通过 employee_id 查看他人数据。
- [x] 阶段数据继续遵守任务读取权限和任务可见范围。
- [x] 页面及接口响应不包含订单金额、单价、小计、成本、利润或外协字段。

## A05 回归与发布

- [x] 前端 Vitest、typecheck、Lint、build 和 bundle 检查通过。
- [x] `git diff --check`、范围/预算/敏感信息检查通过；自动 Vibe 门禁脚本在当前环境不可用。
- [ ] GitHub `master` 与服务器部署 revision 一致。
- [ ] 服务器后端、Nginx 和健康接口正常，现有任务看板和完成项目看板不回归。
